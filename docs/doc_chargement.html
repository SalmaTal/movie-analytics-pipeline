Le chargement pas à pas

Comment les 5 tableaux Parquet d’Aida entrent dans PostgreSQL. Le script fait deux choses bien séparées : d’abord il prépare du texte SQL (aucune donnée ne bouge), ensuite il fait circuler les données, paquet de 5 000 lignes par paquet de 5 000 lignes.

Avant : la transformation a écrit data/processed/ ; schema.sql a créé les tables vides.Après : les 5 requêtes d’analyse et le test d’index de Salma.
